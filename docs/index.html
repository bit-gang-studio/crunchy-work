Crunchy.

Trello for AI. A kanban board and lean docs that live on your machine, which your agent can drive over MCP. 

npx crunchy-work

No account. No API key. No database to set up. Free and MIT.

Or skip the app entirely

claude mcp add crunchy -- npx -y crunchy-work mcp

Your agent gets the tools straight away — no server, no port, no browser. Then open the board when you feel like looking.

What it is

  • Projects — each with one board and its own markdown docs
  • A board — columns and cards, drag and drop, updating live as your agent works
  • Docs — for the context that isn't a task
  • MCP — every capability is a tool, so an agent can do anything you can

What it isn't

Deliberately small. No workspaces, no multiple boards per project, no roles or permissions, no built-in AI chat. If you want those, they belong to Crunchy Team.

Pre-release. Crunchy isn't on npm yet — the commands above won't work until it is. Watch the repository to know when it lands.
